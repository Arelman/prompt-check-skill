## Not read, but worth knowing

- Anthropic, Building agents with the Claude Agent SDK and Writing tools for agents (about building agents, not
  about writing requests).
- Anthropic's interactive prompt-engineering tutorial (https://github.com/anthropics/prompt-eng-interactive-tutorial);
  the overview page notes it was written for older models, so follow the best-practices page where they differ.
- Anthropic's free AI Fluency course (the Delegation, Description, Discernment, Diligence framework).
- The Prompt Report (https://arxiv.org/abs/2406.06608), a survey of prompting techniques.
